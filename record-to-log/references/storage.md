# 保存与外部技能适配

仅在执行保存、追加、更新或同步时读取。保存授权与目的地按主文件判定；技能的用途说明或可用空间列表不等于默认目的地，更不构成写入授权。

## 目的地与降级

- 沿用用户本次对话明确指定的位置，或用户维护的已安装归档 skill 明确定义的默认目的地。没有指定且没有有效默认位置时，先交付可审阅的正文，再询问阻塞保存的位置。
- 本地 Markdown 可直接用可用文件工具创建或更新。若已安装对应外部归档技能，按其连接、定位、当前会话授权与写后校验流程执行；本次授权已足够时不重复索取确认。
- 所需技能未安装、连接不可用或无法验证写入时，交付 Markdown 整理稿并说明实际限制与保存状态；不假称已写入，不擅自换应用或目的地。

## 本机 Craft 适配

- Archive（旧称 Main）/XV：若已安装 `craft-general-archive`，读取其主文件后处理；本机常用路径为 `C:/Users/yongs/.codex/skills/craft-general-archive/SKILL.md`。
- Car：若已安装 `craft-car-archive`，读取其主文件后处理；本机常用路径为 `C:/Users/yongs/.codex/skills/craft-car-archive/SKILL.md`。
- 上述空间只用于路由，不是默认目的地。已明确目的地就沿用；尚未确定时按实际材料与实时结构定位。
- 已整理的日志正文作为写入内容，归档流程主要负责位置、原生呈现与验证，不再扩写成知识文章。内容或目标实质变化时，以当前会话授权及适用归档流程为准。

## 持续记录

- 用户已有目录、命名、标签或日记系统时沿用。新建本地文件且用户未限定命名时，可用 `YYYY-MM-DD-主题.md`；发生日期未知时用 `未定日期-主题.md`，避免把整理日期伪装为发生日期。
- 若需要稳定 ID，在首次实际保存时生成一次，之后保留。文件重命名、重新润色或跨应用复制不代表新事件；不要随文字变化重新生成 ID。
- 多次运行时，先用现有 ID、日期、主题、来源与正文核对重复。相似主题不能证明同一事件；同一事件的新进展也不是重复输入。
- 补记分别标明发生时间与补记时间。用户明确指出录入/转写笔误时，直接按其确认文本修正；事实后续变化、判断修订或正式记录的事实更正，则保留必要历史与关联。类型无法确定时先交付更正稿；若它影响对既有记录的实际修改方式，再询问。
- 既有记录明确需要整体润色时，可在授权范围内更新，不额外制造更正记录。原始材料有重要原话、争议、不可替代证据或用户要求时，保留原文片段、附件或真实来源链接。
- 输出目标与写入结果分别核实。预览、成功保存、部分保存和未写入要准确区分；追加或更正后读取目标位置确认实际内容与顺序。
