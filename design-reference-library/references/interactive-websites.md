# 网站细节与交互采集

归档可访问的交互网站时读取；仅归档截图／视频，或明确只收藏链接入口时，不启动此流程。目标是留下可借鉴、能回看的设计证据，复用主技能的分析、索引和 Craft 写入流程。

## 先定范围与路线

- 默认以用户给出的页面为范围，先看完整页面及主要滚动区域，按侧栏、顶栏、内容、浮层清点独立入口和组件类型。用户圈出的颜色、图标、折叠等位置优先覆盖。只有关键机制需要时才进入关联页，不自动巡检全站。
- 每个独立入口至少查看一次实际响应，包含展开后出现的入口；相同组件的重复实例在确认一致后复用代表状态检查。仅记录差异，不为每行列表、每张卡片重复采样。范围很大时先完成主要机制，明确剩余范围，不能宣称全部检查。
- 清点与操作记录合并成简短工作清单：区域／入口、已检查状态、实际结果或待核验原因。会话中已知的信息直接复用，不额外制作完整测试计划。
- 归档包含查看、展开、切换和筛选等无外部后果的基础核验；保存、删除、发布、发送、支付或连接账户等有外部后果的动作不因归档而执行。需要这类动作才能观察的状态记为未核验，沿用用户已有的明确授权。

## 视觉细节先扫全，再采样

对范围内每个区域检查排版层级、文字与图标颜色、背景、边框、圆角、阴影、间距、对齐和缩进；展开层级还看分组标题、引导线、父子关系和图标对齐。细节不能仅概括为“精致、简洁”，应指出具体做法及其作用。

- 将文字、图标、容器分别看。父按钮的颜色不一定等于内部文字或 SVG 的实际颜色，图标还可能使用填充色、描边色或透明度。
- 对有借鉴价值或用户关注的细节，集中采样默认、悬停、选中、焦点等实际存在的状态；相同样式只采一次，变化处补差异。精确色值、字体、尺寸据页面实际样式，截图目测只描述可见特征。
- 状态切换后等待画面稳定再截图或读值，避免将过渡中间色当最终值。动画确有参考价值时再记录触发、方向、持续方式与结束态；声明值、实际观察和机制推断分开。

## 按组件检查状态与内容联动

只检查页面实际存在、与归档范围有关的类型。下面是覆盖提示，不要求每个网站补齐所有组件，也不代替完整可访问性或响应式测试。

| 类型 | 检查重点 |
| --- | --- |
| 导航与侧栏 | 默认、悬停、选中；折叠／展开后的宽度、标签、图标和内容区变化；有提示时查看提示；代表入口检查键盘焦点与激活反馈 |
| 分组与树形结构 | 每种独立分组的展开／收起及下一层入口；缩进、引导线、父子选中关系；区分真实展开与占位提示 |
| 菜单、提示与弹层 | 打开后的布局、定位、层级和遮挡；选择安全选项以及关闭／取消后的结果；不能只记录触发按钮 |
| 搜索 | 有匹配、无匹配、清空恢复；核对实际列表、数量或高亮变化 |
| 筛选、日期与排序 | 打开、选择、应用／取消／重置中实际存在的路径；核对指标、图表或列表是否联动；预设可能立即生效，先看结果再寻找确认按钮 |
| 标签、表格与图表 | 切换、展开更多／收起、排序或提示中实际存在的行为；核对可见内容变化及布局代价，不只看按钮变色 |

外观相似的入口也可能行为不同，先分别确认响应再归并。占位提示记为占位，受登录或访问限制的状态记为受限；不能把箭头、按钮名称或静态图当作功能已实现的证据。

## 控制往返与证据数量

- 每组操作后集中读取有用的结果和样式，只返回判断所需的摘要。工具支持时合并独立只读采样；依赖前一状态的动作顺序执行。不抓取整页样式、重复全页快照或输出大段页面数据。
- 全页／主要区域图交代结构，局部图交代精细做法，变化图交代独特状态。只有新增信息才截图；同类状态可在文字中合并，不按控件凑图。保留清晰原图，图注说明页面位置、状态与裁切范围。
- 定位失败或等待超时后，先观察当前页面再决定下一步。若界面已经切换，不重复旧动作；确认是占位或限制后停止该分支，不循环重试。提示层未暴露预期语义时，用实际可见证据核对。
- 同一批归档复用已核实的连接、字段映射、来源身份和目标记录；目标、结构或权限变化及写入结果未知时才定向重查。最终写后回读仍须执行。

## 紧凑归档与收尾

正文通常用“视觉细节与状态”和“交互实测”两个短段，也可并入既有合适标题：前者写可复用的具体关系，后者写操作后的实际变化及限制。关键结论对应截图状态或页面位置。调试过程留在工作记录，只有影响采用的结果进入案例；不复制完整清单或样式输出。

例如：“灰色图标降低非当前项权重，当前项的图标与文字同步转蓝，并配浅蓝底”；“日期预设改变了按钮标签，当前测试未观察到指标与图表联动”。区分静态表现与已验证机制，不把全部视觉细节写成用户偏好，也不由基础状态检查推定操作效率提升。

满足以下条件即结束采集并归档：

- 用户指定的细节已有证据，或明确记录无法核验的原因。
- 范围内独立入口的响应、独特组件的相关状态已覆盖；重复实例已确认一致，未覆盖部分已具体标明。
- 图像和简短说明足以还原主要设计做法，继续操作只会重复已知结果。

仅当缺口会改变主要采用判断时继续定向补查。其他页面、多设备、完整键盘路径及后端业务流程不自动扩展；交付如实说明实际覆盖范围，不称“全站交互均已验证”。
