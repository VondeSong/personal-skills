# Car space routing signals

Read this reference only after selecting the `Car` space.

Resolve the live `线束` folder first. Existing title patterns are routing signals, not fixed rules:

- `2_规范与标准`: design rules, processes, terminology, deliverables, and drawing conventions
- `3_物料与选型库`: components, materials, suppliers, selection, and part design
- project documents such as `T29`: project-specific issues, decisions, and evidence
- `5_平台化与横展`: cross-model comparison, commonization, and rollout
- `9_整车电气架构与网络`: electrical functions, controllers, networks, and power relationships
- `7_Catia`: CATIA methods and data-operation issues
- `8_竞品和参考`: competitor and external reference material
- `0 Inbox`: temporary fallback, not a canonical home

Search the live folder and inspect candidate outlines before relying on any of these patterns.
