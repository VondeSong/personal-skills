# 内容压缩与节点转换示例

## 示例一：信息压缩

原文：

```text
DCDC 的作用主要是将动力电池高压直流电转换成车辆 12V 低压系统所需要的低压直流电，
从而为车辆的各种低压电器以及蓄电池充电。
```

白板节点（而不是复制整段话）：

```text
DCDC

高压 DC
   ↓
12V DC

作用：
• 低压系统供电
• 12V 电池充电
```

## 示例二：一个节点一个思想

错误做法——把一整段塞进一个节点：

```text
DCDC 可以将高压电转换为低压电，给蓄电池充电，同时还给其他低压电器供电，
不同车型布置方式可能不同……
```

正确做法——拆成节点 + 连线：

```text
节点：DCDC

连接：
高压 DC → DCDC → 12V DC
                  ├→ 低压负载
                  └→ 12V 电池
```

## 示例三：对比型内容优先用对比图，而不是流程图

原文：

```text
BEV 是纯电动车。
HEV 是油电混合动力，不能依靠外部充电。
PHEV 可以通过充电口给动力电池充电。
增程式汽车主要由动力电池驱动车轮，发动机主要用于发电。
```

内部知识结构：

```text
新能源汽车动力形式

├─ BEV
│  └─ 纯电驱动
│
├─ HEV
│  ├─ 发动机
│  ├─ 电机
│  └─ 不外接充电
│
├─ PHEV
│  ├─ 发动机
│  ├─ 电机
│  └─ 可外接充电
│
└─ EREV
   ├─ 电机驱动车轮
   └─ 发动机主要发电
```

这种情况应该优先选择**对比型思维导图**，而不是流程图——内容本质是"几个并列选项的特征对比"，不是"先后步骤"。

## 示例四：中心节点要提炼主题，不要照抄页面标题

页面标题：

```text
新能源汽车动力形式学习笔记
```

中心节点不要直接写"当前页面"或原样复制标题里的"学习笔记"这类无信息量的词，应该提炼真正主题：

```text
新能源汽车动力形式
```
