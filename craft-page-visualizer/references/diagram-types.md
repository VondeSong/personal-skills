# 图形类型选择指南

不要默认所有内容都生成思维导图。根据内容特征选择最合适的类型，一个白板只保持一种主要视觉逻辑。

## 打分方式（内部使用，不向用户展示）

可以为内容在以下维度打分，取最高分对应的类型：

```text
hierarchyScore      层级分（分类、从属关系明显）
sequenceScore       顺序分（步骤、先后关系明显）
relationshipScore   关系分（实体间的连接、依赖）
comparisonScore     对比分（A vs B、优缺点、方案对比）
timelineScore       时间分（日期、阶段、版本顺序）
causalScore         因果分（原因导致结果）
systemScore         系统分（模块、架构、组成关系）
```

大致对应：
- `sequenceScore` 最高 → 流程图
- `hierarchyScore` 最高 → 思维导图 / 层级树
- `systemScore` + `relationshipScore` 高 → 系统结构图
- `causalScore` 高 → 因果关系图 / 问题分析图
- `comparisonScore` 高 → 对比图
- `timelineScore` 高 → 时间线

---

## 思维导图 Mind Map

**适用**：主题 → 分类 / 概念 / 特点 / 方法 / 注意事项。典型场景：学习笔记、知识总结、软件介绍、概念解释、读书笔记。

```text
主题
├─ 分类
├─ 概念
├─ 特点
├─ 方法
└─ 注意事项
```

## 流程图 Flowchart

**检测关键词**：首先、然后、接着、完成后、如果、否则、步骤、流程、操作、输入、输出。检测到大量此类词汇时优先生成流程图。

```text
输入
 ↓
分析
 ↓
是否满足条件？
 ↙       ↘
是        否
↓         ↓
执行     返回修改
```

## 系统结构图 System Diagram

**适用**：软件架构、汽车电气、API、网络结构、模块关系、硬件组成。

```text
             电池
              │
       ┌──────┴──────┐
       ↓             ↓
前舱电器盒       DCDC保险丝盒
                     │
                     ↓
                   DCDC
                     │
                     ↓
                  低压系统
```

## 因果关系图 Causal Diagram

**检测关键词**：因为、导致、所以、因此、原因、结果、影响。

```text
原因 A ─┐
原因 B ─┼→ 核心问题 → 影响 → 结果
原因 C ─┘
```

## 问题分析图 Root Cause

**适用**：质量问题、故障分析、Root Cause、4D/5D、工程问题。

```text
问题现象
    ↓
问题机制
    ↓
可能原因
    ↓
根本原因
    ↓
┌─────────┐
│         │
临时措施   永久措施
```

## 对比图 Comparison

**检测关键词**：A vs B、优点、缺点、区别、方案一、方案二。

```text
        核心问题

    A            B
    │            │
 特点          特点
 优点          优点
 缺点          缺点
    │            │
    └────结论────┘
```

## 时间线 Timeline

**适用**：存在大量日期、年份、阶段、版本、时间顺序的内容。

```text
2024
 ↓
事件 A
 ↓
2025
 ↓
事件 B
 ↓
2026
 ↓
当前状态
```

## 层级树 Hierarchy Tree

**适用**：分类体系。

```text
知识库
├─ 工作
│  ├─ 项目
│  └─ 技术
├─ 学习
└─ 生活
```

## 混合知识图 Hybrid Diagram

如果页面同时具有多个明显结构，可以用混合白板：一个主结构 + 局部子结构。

```text
                    核心主题
                       │
        ┌──────────────┼──────────────┐
        ↓              ↓              ↓
      背景            原理            应用
                       │
                 ┌─────┴─────┐
                 ↓           ↓
              流程 A       流程 B
```

**但要注意**：一个白板只能有一个主要视觉逻辑，不要同时堆积大量不同图形导致混乱——混合图的意思是"主结构上挂局部子结构"，不是"几种图并排放"。
