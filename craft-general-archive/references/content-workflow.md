# 共用内容整理流程

Archive、XV、Car 在确定空间后、检索和拟稿前都读取本文件。它只维护定位与编辑方法；空间、连接、授权、专业事实判断由当前执行 skill 决定，读取本文件不转交任务。

## 找到真正的承载位置

先区分定位查重与知识关联：前者确认写到哪里、是否重复，后者查找可复用的方法、依据或案例。目标已明确时直接读取目标及必要上下文；普通合集记录读取所属合集、实时 schema、相关记录和来源即可，不必每条重扫空间目录。以下渐进定位适用于归属未明或需要判断新知识承载位置的内容。

1. 读取实时目录和相关顶层标题，提取材料的主题、用途、项目、时间、来源与有区分度的同义词。
2. 少量定向搜索后，读取最匹配页面的提纲、相关正文及相邻块；没有精确标题匹配时继续查正文和同义词。
3. 比较页面目的、知识类型、主题范围、适用范围、内容粒度、重复和冲突。索引、概览、引用页用于导航；详细知识优先进入实际承载页，必要时在索引补链接。
4. 确定完整路径、实际页面 ID、具体小节及前后锚点。标题相似、根文档名称相同或搜索命中本身都不能证明位置正确。
5. 已有内容相同时复用位置；确有补充且范围一致时追加；主题独立且无适当承载页时考虑新页；通用知识与项目事实按需分小节或分页面，并保留共同来源和关联。

证据不足才扩大检索，不默认导出整个空间，不把缓存目录当现状。找不到锚点时重新检查承载页；新小节必须延续该页目的，不能习惯性在页尾堆积独立材料。调整既有目录或重写既有正文仍受当前任务授权约束。

## 创建前的语义查重与复用

创建属性列、合集记录或独立知识页前必须判断是否已有同一对象；查重是固定动作，知识关联检索仍按下一节触发。结合别名、缩写、旧称、同义表达及内容识别对象，读取候选属性或正文与上下文，不以标题相同或不同直接判定。

| 拟创建对象 | 查重范围与复用方式 |
| --- | --- |
| 属性列 | 读取目标合集的实时 schema，比较字段含义、粒度、类型及单位；语义一致且类型兼容时复用原字段键，不为同义列名再建一列。显示名相同也可能用途不同，不能仅凭列名合并 |
| 普通项目实例记录 | 先查目标合集及同项目相关记录，比较对象、项目／车型、配置、版本和记录用途等实际有区分度的信息；已是同一条记录则复用。跨项目或不同问题的实例可分别保留，共用适用的方法页 |
| 可复用对象、概念等知识实体型记录，或独立知识页 | 在当前目标空间按同义表达定向检索，核实内容职责与适用范围；已有同一知识承载页则复用或链接，不因名称不同或位于别的合集而复制正文 |

已有同一记录时继续使用其 ID；已有知识页时按需建立引用。确需在当前合集管理一个项目实例时，可新建实例记录并关联共用知识，但不声称两个条目共用同一个记录页面。仅为另一种展示方式时优先复用视图或链接，不为“借用页面”擅自移动、合并已有记录或复制知识；改名、补属性及合并仍遵守既有授权边界。无法确认是否同一对象时保留差异并说明待核，不直接合并。

同批按对象分组查重，复用已核实的同义词、候选 ID、适用范围与判定依据，不为每条重复搜索；特殊条件、冲突或信息缺口再补查，结果的新鲜度按下节处理。

## 关联检索按需触发，同批复用

先判断关联需求，不以对象在 Craft 中属于页面作为触发条件，也不要求每页或每条记录都加双链。

| 内容或操作 | 检索与核实范围 |
| --- | --- |
| 新建方法、规范、概念等独立知识页 | 定向查找已有承载页、重复和冲突，优先复用；无可靠关联可不建链 |
| 案例、评审、试验记录，或记录正文新增分析和技术判断 | 按实际问题查找适用方法、依据或案例；记录正文与独立页面按同一内容标准判断，不因位置不同省略所需依据 |
| 普通合集新增记录，仅填写来源支持的名称、区域、分类等属性 | 核对所属合集、重复记录及来源，不默认逐条做空间级知识关联检索；分类涉及新增推断时按上一行处理 |
| 新增或修改实际链接、填写“相关知识”等关联字段 | 目标不明时定向检索；目标 ID 已明确时直接读取。建链前核实目标内容、关联用途和适用范围，不能仅凭标题匹配 |
| 仅新增属性列、改列名、调整视图、排序或样式 | 核对目标、schema 与受影响数据，无需知识关联检索；新增关联字段不要求立即填满 |

用户要求关联一批记录时，按主题、对象类型或问题类型集中检索。同一批次、同一空间中，复用已读候选的 ID、相关内容、来源版本与适用条件；逐条比较适用性，只有特殊条件、冲突或信息缺口需要补查，不为相同候选重复搜索和读取。跨批次或空间、目标已变、版本或适用条件不同、内容可能已更新时重新核实，不把旧检索结果当实时事实。

目标可以是知识页、具体段落或另一条合集记录。知识页读取相关正文及上下文；记录页可结合属性、所属合集和必要正文核实，正文为空不等于无有效信息。不可访问、无足够信息或仅名称相似的目标不建立关联；无可靠匹配允许留空，不表示没有相关要求。用户限定单一来源或仅原样归档时遵守指定，不为补齐关联擅自扩展技术结论。

## 先组织知识，再选择样式

- 先判断读者要解决什么问题，写出直接回答或阅读目的，再沿概念、关系、方法、实例展开。短内容保持短，不为了套模板扩写。
- 归档路径、候选评分、工具限制等属于任务反馈，不默认写进知识正文。知识类型、项目和版本只呈现实际有用的字段，不堆“未提供”占位项。
- 连接已有内容：沿用术语和局部标题层级，指出新增知识与既有知识的关系；避免每次追加都重写定义、背景和来源大段说明。
- 去除重复和口语赘述，保留关键事实、限制、单位与来源。只有获得修改授权才把补充融合进既有原文；否则在合适锚点追加自然衔接的内容。
- 解释、例子和对比应帮助理解真实材料；AI 补充标明身份，不能虚构项目事实或把推断写成定论。按需提炼可复用方法，具体项目数据保留原始边界。
- 多个结论共用来源时可集中放一条来源说明；不同来源、冲突、关键推断就近标注。完整出处可放文末，关键适用条件留在相关结论旁。
- 原图与原文件保留证据价值，正文提炼读者需要的知识；只有逐行数据确有用途或用户要求时才全文转录。

新页或重大追加读取 [共用排版规范](craft-presentation.md)，以内容目的选原生块。结构应便于理解和回顾，不要求每篇都出现摘要、风险、表格、卡片和图。

## 提交前的阅读检查

从读者视角检查：开头能否知道讲什么、有什么用；正文是否连贯；关键条件能否和结论一起看到；例子是否有助理解；来源是否能追溯；新增内容是否融入目标页。优先修正含混和重复，再增加装饰。

预览按“目标与操作 → 可审阅正文 → 重要来源/附件/视觉选择”组织。只解释会影响用户判断的分析，不要求用户阅读整套内部检查表。授权方式仍取自执行 skill 与当前会话。
