# Craft 写入与恢复协议

在实际写入前读取。Archive/XV 与 Car 共用本文件，汽车版不再维护独立协议。本协议只定义执行步骤；授权方式由当前执行 skill 的主文件与当前会话决定，不新增确认要求，也不放宽授权范围。通用 skill 仅写 Archive/XV，专业 skill 仅写 Car。

## 执行前

1. 确认当前内容单元已获得主文件要求的授权。上传、建页、追加、更新和交叉链接都是写入。
2. 重新核对实时空间名称、完整目标路径、页面与插入锚点；不能跨空间复用 ID。
3. 用来源标识（如文件名+版本+页码）及有区分度的文本检查重复，读取命中上下文。创建属性列、记录或知识页前按[语义查重规则](content-workflow.md#创建前的语义查重与复用)核实同义名称、对象身份及适用范围，不能只比标题；同批复用已核实结果。主题相同不一定重复。已存在同一对象或相同内容时报告并复用已有位置，不再写一份。
4. 若实时状态使计划实质改变：预览确认模式重新预览；直接模式仅能在当前授权范围且仍满足置信度要求时继续，否则澄清。
5. 记录此次操作的目标、预期正文/来源标识、返回块 ID 与结果。更新既有内容前保存原正文与必要属性以供比对；不能保存可靠快照时不做不可恢复的原文覆盖。

## 写入与验证

- 以当前 MCP schema 或已验证 API 契约为准；参考示例不是字段支持的保证。不支持的样式可在授权范围内降级，并说明限制；不支持关键附件或层级则暂停依赖该能力的操作。
- 对每次返回的创建结果记录块 ID。计划含正文的独立页或合集记录，回读其自身子内容确认正文归属，父页的同级正文不是成功。仅字段的合集记录按记录 ID、属性、来源与所属合集验收，不要求补非空正文；新增属性列按 schema 与旧数据保留情况验收，不当作创建页面。
- 图片使用实际 MIME 类型，校验返回的是 image 块；文件校验附件存在及可追溯位置。不能用一段文件名文字冒充上传成功。
- 回读文字、单位、来源、适用范围、标题层级、callout、语义颜色、卡片、分隔线、媒体顺序及图注；搜索独特文本核实路径与重复项。
- 如使用焦点、折叠、公式、Mermaid、白板或页面级样式，核对实际原生类型、属性和内容归属。折叠不能为空壳，卡片须有子内容；关键结论、适用条件和风险在折叠外可见。公式/图表核对可编辑源与预期类型，可用时打开页面检查渲染、截断和阅读顺序；保存了源文本不能等同于图已正确显示。
- 阅读验收采用 [共用排版规范](craft-presentation.md)：开头主旨明确、正文连贯、增量内容融入承载页、强调有主次、来源不喧宾夺主。若只有样式属性正确但正文重复或难读，先在授权范围内修正当前写入内容。
- 从结构检查移动端阅读顺序；仅有 API 回读不能声称已在手机上视觉测试。无法验证样式时，内容正确才可报告内容归档成功，并列出视觉限制。

## 超时、失败与回滚

- 超时或响应丢失意味着结果未知。先回读目标并按来源与独特正文查找。已完整写入则验证并继续，不重复提交；部分写入先列出可证实的已创建块与缺失项。
- 只有确认没有落盘时才重试一次。仍无法确定状态则停止后续依赖操作，报告已知结果与不确定部分；不得循环重试或按标题批量删除。
- 图片上传出现 `ProxyError`、`RemoteDisconnected` 或响应丢失时，读取 [上传连接恢复](upload-transport-recovery.md)。在确认未落盘、诊断支持代理路径问题且直连空间核验成功后，可按该协议进行一次有依据的直连补传；不要仅因同一路径重试失败就宣布 API 不可用。状态不明仍必须停止。
- 当前操作创建的块可在归属可证明、没有他人后续编辑且删除不会波及其他内容时有限回滚。不能证明属于当前操作的块不得删除；不得递归删除含他人新增内容的子页。
- 修改既有内容后发生不一致时，只有可确认当前内容仍是本次写入结果且没有并发变更，才在原授权范围内恢复快照；否则保留现场，报告差异并请求处理意见。
- 多空间分别执行与验证，准确报告部分成功。默认保留成功部分；用户要求全有或全无时，必须在预览中说明 API 不提供跨空间事务、补偿也可能失败，不能承诺原子性。

## 链接与结果

从本次实时结果取得 space/document/target block ID。优先链接嵌套页；直接追加可链接保留上下文的内容块。

可尝试 `https://docs.craft.do/editor/d/{spaceId}/{documentId}/b/{targetBlockId}/{urlEncodedTitle}`，但只有在用户已登录的 Craft 浏览器中实际打开并确认到达正确页面，才称为已验证链接。该步骤失败不否定已校验的内容写入：返回准确空间与路径，并说明链接未能验证。

`craftdocs://` 是应用深链。不得仅为了生成链接发布页面或开启秘密分享。去除临时参数，不输出连接凭据、会话令牌或无关内部 ID。
